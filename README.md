# Etch a Sketch
## Description
It's a etch-a-sketch, so you can paint through small, medium or big squares, you are the one who chooses. In the first main button above the grid, input a number which will be the quantity of squares generated for width and height. Note: the width and height of the main grid won't change

## Usage
access the following link -> https://rayssarrsilva.github.io/Etch-a-Sketch/
click the "Change size" button and input a number between 1 and 100 to generate the square size (n x n)
hover the mouse over the div squares to paint in your sketch
reload the page if you wanna erase what you painted
